ПРОБЛЕМА: Gold показывал 502: CME HTTP 403; eSignal HTTP 403.
Это запрет автоматических запросов со стороны этих веб-сайтов.

ИСПРАВЛЕНИЕ:
- /GoldServlet теперь читает HTML сайта Google Finance:
  https://www.google.com/finance/quote/GCW00:COMEX?hl=en
  Цена относится к биржевому фьючерсу GCW00 (COMEX).
- Если основной источник не отвечает, пытаемся прочесть HTML
  https://markets.businessinsider.com/commodities/gold-price
  Это СПОТОВАЯ цена, а не фьючерс! Отличие показывается пользователю.
- Если оба сайта запрещают доступ, выводится реальная ошибка, без подмены.

ЧТО НУЖНО СДЕЛАТЬ:
1. Удалить/закрыть старые экземпляры серверного процесса NetBeans.
2. Открыть Lab3Server и Lab3Client ИМЕННО из этого архива.
3. Сначала запустить Lab3Server (ServerMain), затем Lab3Client.
4. Нажать Gold.

Только Java: HttpURLConnection, BufferedReader, регулярные выражения.
Никаких JavaScript, JSON, Python.

ПРИМЕЧАНИЕ: Доступность сайтов на компьютере пользователя не гарантирована.
Если обе страницы показывают 403, требуется согласованный поставщиком
способ доступа к биржевым данным. Нельзя честно обещать реальную цену
через сайт, который блокирует автоматизированные запросы.
