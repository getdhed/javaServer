Лабораторная №3: PostgreSQL + Java JDBC
======================================
1. Установите PostgreSQL (и pgAdmin при необходимости).
2. Выполните Lab3Server/sql/create_database.sql под пользователем postgres.
   ОБЯЗАТЕЛЬНО замените CHANGE_ME_STRONG_PASSWORD на свой пароль.
   Если PostgreSQL сообщает, что пользователь или база уже существуют,
   не создавайте их второй раз.
3. Подключитесь к БД lab3_dictionary под lab3_user и выполните
   Lab3Server/sql/init.sql. Создаст таблицу translations и 15 пар слов.
4. Скачайте официальный PostgreSQL JDBC Driver (postgresql-42.7.x.jar)
   с https://jdbc.postgresql.org/download/ . В NetBeans:
   правый клик Lab3Server -> Properties -> Libraries -> Compile -> Add JAR/Folder.
   Выберите скачанный JAR. Убедитесь, что JAR есть также в runtime classpath.
   JAR драйвера не включён в архив: в среде сборки нет доступа для скачивания.
   Для Tomcat JDBC JAR потребуется поместить в WEB-INF/lib внутри WAR,
   либо добавить драйвер в lib контейнера.
5. Для Windows PowerShell ПЕРЕД запуском NetBeans из того же окна:
   $env:LAB3_DB_URL='jdbc:postgresql://localhost:5432/lab3_dictionary'
   $env:LAB3_DB_USER='lab3_user'
   $env:LAB3_DB_PASSWORD='ВАШ_ПАРОЛЬ'
   & 'C:\Program Files\NetBeans\netbeans\bin\netbeans64.exe'
   (путь к NetBeans уточните на компьютере)
   ИЛИ задайте эти переменные в системных настройках Windows,
   перезапустите NetBeans (НЕ включайте пароль в Git).
6. Запустите Lab3Server, потом Lab3Client.
   Перевод: кот -> cat, обратный перевод: dog -> собака.
   Проверка HTTP:
   http://localhost:8080/MyServlet?txt=cat&dir=en&format=text
   Для проверки реально SQL: INSERT INTO translations(word_ru,word_en)
   VALUES ('тест','test'); затем попробуйте перевести 'тест'.
7. Сообщение HTTP 503 означает ошибку БД/настроек/драйвера, смотрите
   консоль Lab3Server. Ошибка 'No suitable driver' = нет JDBC JAR в runtime.

Важно: перевод работает только через PostgreSQL, без fallback в файл.
Остальные функции (Word, Gold, Music) сохранены. Клиент к БД не подключается.
